# Code of Conduct

Everyone participating in the DevDoctor project — issues, pull requests, discussions — is
expected to be respectful, constructive and welcoming.

- Be kind. Assume good intent; ask before judging.
- Focus on the problem, not the person. Critique code and ideas, never people.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Respect differing experience levels: DevDoctor exists precisely because environments are
  confusing.

Maintainers may edit, remove or reject contributions and comments that violate these rules and
may temporarily or permanently ban participants for repeated or serious violations. Report
unacceptable behaviour privately to the maintainers.

This code of conduct is adapted from common open-source community guidelines and applies to all
project spaces.
